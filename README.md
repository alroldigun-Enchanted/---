# Навигация для незрячих с сонарным датчиком на собаке-поводыре
**Концепция ассистивной навигационной системы**
**Дата первой публикации идеи:** февраль 2026  
**Дата фиксации на GitHub:** 17 сентября 2026
## Проблема
Незрячие люди, использующие собаку-поводыря, получают ограниченную информацию об окружающей среде. Собака помогает избегать препятствий, но не передаёт детальную картину пространства (расстояние, форма объектов, свободные проходы и т.д.).
## Суть идеи
Небольшое устройство (в стиле AirTag или компактного датчика), закреплённое на собаке-поводыре, сканирует окружающее пространство с помощью ультразвуковых / сонарных датчиков в реальном времени.  
Данные передаются на смартфон, обрабатываются и преобразуются в голосовые подсказки, которые человек получает через Bluetooth-наушники. Система даёт направленную информацию о пространстве («препятствие справа в 1,5 метра», «свободный проход прямо» и т.п.).
## Основные компоненты
- Компактный датчик на собаке-поводыре
- Передача данных на смартфон в реальном времени
- Обработка и преобразование в голосовые инструкции
- Вывод через Bluetooth-наушники
## Целевая аудитория
Незрячие и слабовидящие люди, использующие собаку-поводыря.
